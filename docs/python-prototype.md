# 流媒体下载 GUI

新版桌面界面位于 [Flutter 工程](../desktop/README.md)。以下说明适用于 Python 原型。原型中的图形选轨、点播选段、本地与远程 IPTV 频道选择已迁移到 Flutter 版（见 [使用说明](usage.md#图形化选轨选段与-iptv-频道)）；本文件保留作为对照与原型自身的操作说明。

Windows、macOS 和 Linux 桌面版，面向 x64 和 ARM64。

## 启动

安装 Python 3.11 或更新版本，并确保该 Python 可导入 tkinter。Linux 上通常需要额外安装发行版的 Tkinter 软件包。安装 FFmpeg 并把它加入 PATH 后，在本目录执行：

```sh
python app.py
```

首次启动时点击「安装 / 更新核心」。然后粘贴 HLS、DASH 或 MSS 的 HTTP(S) 清单链接，选择保存目录，点击「开始下载」。程序使用上游的自动选轨。下载失败时可以查看任务日志。

## 核心更新

更新按钮读取 [上游 GitHub Release](https://github.com/nilaoda/N_m3u8DL-RE/releases/latest)，下载当前平台的发行包，检查大小和发布记录中提供的 SHA-256，运行新版的 `--version` 后才切换。核心独立存放在用户数据目录。更新失败时，原有核心仍可继续使用。旧版核心保留在磁盘上。

GUI 通过子进程调用 [N_m3u8DL-RE CLI](https://github.com/nilaoda/N_m3u8DL-RE)，通过退出码判断任务是否成功。此版本每次运行一个任务。任务列表可以按状态筛选，点击任务可以查看对应日志，任务记录保留至窗口关闭。

## 下载选项与工具

点击「选项与工具」打开图形表单。选择下载、拼接文件、合并媒体、混流轨道或检测环境。下载支持粘贴链接或浏览本地清单。表单根据已安装核心的帮助生成，开关可以选择默认、启用或关闭，带值的选项可填写，文件和目录可浏览。请求头等可重复选项可添加多项。

可按参数名称或说明搜索。混流格式、混流程序、字幕和轨道保留可直接选择。可通过「设置筛选」填写轨道条件，通过「选择本地 IPTV 频道」多选频道。「读取轨道」尝试通过核心的元数据生成视频、音频和字幕下拉框。远程 IPTV 可从地址框加载 HTTP(S) M3U 列表并选择频道。预览支持表单中的请求头、Netscape Cookie 文件及 HTTP(S) 代理。手动填写的请求头只发送到初始 URL。对于核心元数据提供 PeriodIndex 的 DASH 点播，轨道窗口同时显示分段和时长，可取消选择不需要的分段。HLS 点播则使用核心选中轨道元数据中的不连续序号。读取轨道时以自动选择的轨道预览 HLS 分段。表单覆盖范围取决于当前核心的帮助格式。






## 核心功能随发行版本变化

工具菜单会读取当前核心的帮助，只显示该核心明确支持的子命令。轨道预览中的分段控件也取决于该版本是否支持排除分段。源码检出目录用于对照，应用运行时使用通过「安装 / 更新核心」获取的官方可执行文件。


GitHub API 限流时，核心更新会改用同一仓库的官方发行页查找发行包。下载仍来自 GitHub。通过 API 获取到大小和 SHA-256 时会进行校验，两种路径都要解包并试运行版本检查后才会切换。Python 无法建立连接时，如系统提供 curl，也会尝试使用系统的网络客户端。
