# SegmentDesk 使用说明

## 安装与首次运行

从源码运行或构建，请参阅 [Flutter 桌面工程](../desktop/README.md)。如果使用 Windows 构建包，解压整个包后运行 `stream_download.exe`，保留同目录的 DLL 和 `data` 文件夹。

核心安装需要能访问 GitHub，并使用系统上的 `curl` 和 `tar`。媒体任务通常需要 FFmpeg。安装后，在终端运行 `ffmpeg -version` 可检查 PATH 是否生效。如果修改了 PATH，重新打开客户端。

首次启动，点击左侧 **安装核心**，等待显示版本号。之后用同一位置的 **检查更新** 更新核心。客户端会在试运行成功后切换到新版。

## 下载链接

1. 点击右上角 **新建下载**。
2. 粘贴完整的 HTTP(S) 媒体清单链接，例如 HLS 的 `.m3u8` 或 DASH 的 `.mpd`。普通视频播放页面需要先取得媒体清单链接。
3. 选择保存目录，可选填文件名，然后点击 **开始下载**。
4. 在任务列表选中该任务，查看状态和日志。

普通下载会使用自动选轨。可在 **设置 → 下载偏好** 中修改默认目录与混流格式。

## 本地清单与高级选项

在左侧打开 **选项与工具**。可以粘贴链接，也可以通过文件选择器打开本地清单。使用搜索框查找参数说明，例如请求头、限速、录制时长或选轨筛选。控件来自已安装核心的帮助，因此不同版本的可用设置可能不同。

拼接、合并、混流与环境检测仅在核心支持时出现在操作下拉框。运行后，结果会显示在主窗口的任务日志中。

## 外观与故障排查

- 在 **设置 → 外观** 选择主题色，或切换浅色、深色与跟随系统。保存后会应用到当前窗口，并在重启后保留。
- **核心安装失败**：查看窗口底部的错误信息，确认网络能访问 GitHub 官方发行页，并确认 `curl` 和 `tar` 可用。
- **找不到 FFmpeg**：确认 `ffmpeg -version` 可执行，再重启客户端。
- **看不到某项工具或参数**：查看核心版本并尝试检查更新。官方发行版的功能可能少于上游主分支。
- **任务失败**：在任务列表中选中该任务查看退出码和日志。提交问题时可附上系统、客户端版本、核心版本和经过脱敏的日志。
